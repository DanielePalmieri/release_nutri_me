Norme sulla Privacy / Privacy Policy

Ultimo aggiornamento / Last updated: 29 Ottobre 2026

La presente Informativa sulla Privacy descrive come l'applicazione desktop Nutri Gestionale (nota anche come NutriMe), sviluppata da Daniele Palmieri (d.palmieridev@gmail.com), raccoglie, utilizza, conserva e protegge i dati dell'utente, inclusi i dati ottenuti tramite le API di Google OAuth 2.0 e Google Calendar.

1. Architettura Locale ("Local-First") e Raccolta Dati

Nutri Gestionale è un'applicazione desktop che funziona interamente in locale sul computer Windows dell'utente:

  • Tutti i dati inseriti nell'applicazione (anagrafiche pazienti, misurazioni antropometriche, piani alimentari, appuntamenti e fatture) sono salvati esclusivamente in locale sul dispositivo dell'utente in un database SQLite locale.
  • Lo sviluppatore di Nutri Gestionale non gestisce alcun server cloud centrale e non ha accesso ad alcun dato clinico, personale o contabile inserito nell'applicazione.

2. Dati Google Acquisiti tramite OAuth 2.0 (Google User Data Accessed)

Il collegamento con Google Calendar è completamente opzionale e viene attivato solo su esplicita richiesta dell'utente nella sezione Impostazioni → Google Calendar. Quando l'utente autorizza il collegamento, Nutri Gestionale richiede esclusivamente i seguenti ambiti di autorizzazione (OAuth scopes):

  • openid e email: utilizzati unicamente per leggere l'indirizzo email dell'account Google collegato e mostrarlo nella schermata delle impostazioni dell'applicazione.
  • https://www.googleapis.com/auth/calendar.app.created: ambito ristretto e non invasivo che consente a Nutri Gestionale di creare un calendario secondario dedicato (denominato "Studio Nutrizione") e di creare, aggiornare o eliminare esclusivamente gli eventi all'interno di tale calendario secondario creato dall'app.

Nutri Gestionale NON ha accesso al calendario principale dell'utente né ad altri calendari preesistenti sull'account Google dell'utente.

3. Come Utilizziamo i Dati di Google (How We Use Google User Data)

  • L'indirizzo email Google (email) viene mostrato nell'interfaccia locale di Nutri Gestionale per indicare quale account Google è attualmente sincronizzato.
  • Il permesso calendar.app.created viene utilizzato esclusivamente per sincronizzare gli appuntamenti fissati nell'agenda di Nutri Gestionale verso il calendario secondario dedicato "Studio Nutrizione", così che il professionista possa consultare i propri appuntamenti di studio anche da smartphone o web tramite Google Calendar.
  • I dati ottenuti dalle API di Google non vengono mai utilizzati per profilazione, pubblicità, ricerche di mercato o addestramento di modelli di Intelligenza Artificiale.

4. Archiviazione e Protezione dei Dati (Data Storage and Security)

  • Il token di aggiornamento OAuth 2.0 (refresh_token) rilasciato da Google viene cifrato e custodito esclusivamente sul computer locale dell'utente tramite le API crittografiche native del sistema operativo (Windows Data Protection API / Electron safeStorage).
  • Tutte le comunicazioni dirette tra il computer dell'utente e le API di Google (oauth2.googleapis.com e www.googleapis.com/calendar/v3) avvengono tramite protocollo sicuro HTTPS/TLS.
  • I file di backup generati dall'utente (.nutribak) sono protetti mediante cifratura autenticata AES-256-GCM con chiave derivata da password tramite Argon2id e non includono i token di sessione OAuth.

5. Condivisione e Trasferimento dei Dati a Terzi (Data Sharing and Transfers)

Nutri Gestionale non vende, non affitta, non condivide e non trasferisce a terze parti alcun dato personale o dato proveniente dalle API di Google. Poiché l'applicazione opera interamente sul dispositivo locale dell'utente, lo scambio dei dati del calendario avviene direttamente tra il computer dell'utente e i server ufficiali di Google LLC.

6. Conservazione, Revoca e Cancellazione dei Dati (Data Retention and Deletion)

I dati e i token OAuth rimangono memorizzati sul computer dell'utente finché l'utente mantiene attivo il collegamento. L'utente può revocare l'accesso ed eliminare i dati in qualsiasi momento:

  • Dall'applicazione Nutri Gestionale: aprendo Impostazioni → Google Calendar e cliccando su Scollega. Questa azione revoca immediatamente il token presso Google ed elimina in modo definitivo il token e i riferimenti di sincronizzazione dal database locale.
  • Dal proprio Account Google: visitando la pagina Sicurezza e autorizzazioni dell'Account Google (myaccount.google.com/permissions) e rimuovendo l'accesso a Nutri Gestionale.
  • Disinstallazione o eliminazione locale: l'utente può cancellare l'intero archivio locale o disinstallare l'applicazione dal proprio PC in qualsiasi momento.

7. Conformità alla Google API Services User Data Policy (Limited Use Disclosure)

L'utilizzo e il trasferimento da parte di Nutri Gestionale a qualsiasi altra applicazione delle informazioni ricevute dalle API di Google rispettano la Google API Services User Data Policy, inclusi i requisiti di Utilizzo Limitato (Limited Use requirements).

English Summary & Limited Use Disclosure:
Nutri Gestionale's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Specifically: (1) Nutri Gestionale is a local-first desktop application; all application data and OAuth tokens are stored exclusively on the user's local device, with tokens encrypted via OS-level DPAPI (safeStorage). (2) Nutri Gestionale accesses only openid, email (to display the connected Google account address in the app settings), and https://www.googleapis.com/auth/calendar.app.created (exclusively to create and synchronize appointments inside a dedicated secondary calendar created by the app). (3) Nutri Gestionale does not read the user's primary calendar, does not transmit any user data to external third-party servers, does not share or sell Google user data to third parties, and never uses Google user data for advertising or AI/ML model training. (4) Users can revoke access and delete all stored OAuth credentials at any time by clicking "Scollega" (Disconnect) in Settings → Google Calendar, or via Google Account Permissions.
